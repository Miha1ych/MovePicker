# 🎬 Movie Picker

> Удобный подбор фильмов и сериалов прямо в браузере.

Movie Picker - расширение, которое помогает быстро находить фильмы и сериалы по жанру, рейтингу, году и другим параметрам.

Никаких бесконечных списков и десятков вкладок — выбрал параметры, нажал поиск и получил подборку.

## 📦 Установка

### Chromium

1. Скачайте архив `MovePicker Cromium.zip`
2. Распакуйте его в удобное место
3. Откройте страницу расширений браузера
4. Включите **Режим разработчика**
5. Нажмите **Загрузить распакованное расширение**
6. Выберите папку с `manifest.json`

### Firefox / Zen

1. Скачайте архив `MovePicker FireFox.zip`
2. Распакуйте архив
3. Откройте:

`about:debugging#/runtime/this-firefox`

4. Нажмите **Load Temporary Add-on…**
5. Выберите `manifest.json` из папки Movie Picker

> ⚠️ В Firefox/Zen такая установка является временной и может потребовать повторной загрузки расширения после перезапуска браузера.

---

## 🚀 Быстрый запуск

После установки Movie Picker можно открыть сочетанием:

**`Ctrl + Shift + Y`**

Также расширение можно закрепить на панели браузера и запускать через его иконку.

---

## Как это работает

Movie Picker использует **The Movie Database (TMDB)** для получения информации о фильмах и сериалах.

Поиск → фильтры → подборка → выбор фильма → информация и трейлер.
