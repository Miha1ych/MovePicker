# Movie Picker

Программа, чтобы быстро найти, что посмотреть вечером. Фильмы и сериалы, подборки под твой вкус, избранное — всё в одном окне.

Делал для себя, потому что надоело по полчаса листать списки. В итоге выросло в нормальную программу.

## Что умеет

- **Для тебя** — ставишь лайки фильмам, программа подбирает похожие. Чем больше лайков, тем точнее.
- **Подбор** — не знаешь, что хочешь? Выбираешь настроение и жанр, и она сама предложит пару вариантов. Есть режим «на двоих», если выбираете с кем-то.
- **Похожие** — открыл фильм, нажал «Похожие» и получил ещё десяток в том же духе.
- **Избранное** — отложить на потом, чтобы не потерять.
- **Фильтры** — жанр, год, рейтинг, возраст, сортировка.
- **Трейлеры и кадры** прямо в карточке фильма.
- **8 тем оформления** и настройка размера интерфейса.
- Клик по названию копирует его, удобно искать дальше.
- Горячая клавиша **Ctrl+Shift+Y** открывает программу откуда угодно. Живёт в трее и не мешает.

## Установка

1. Скачай `MoviePicker-Setup-X.X.X.exe` со [страницы](https://miha1ych.github.io/MovePicker).
2. Запусти. Если Windows пишет «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**. Это потому, что программа не подписана платным сертификатом, с ней всё нормально.
3. При первом запуске нужен ключ TMDB (см. ниже).

## Ключ TMDB

Все данные о фильмах берутся с [TMDB](https://www.themoviedb.org/). Им нужен бесплатный ключ:

1. Зарегистрируйся на themoviedb.org.
2. Зайди в Настройки → API и создай ключ (пишешь, что для личного пользования).
3. Скопируй **API Read Access Token** (длинный, начинается с `eyJ...`) и вставь в настройках программы.

Занимает минуты три. Ключ хранится только у тебя на компьютере.

## Если медленно грузится

Если постеры не грузятся или всё тормозит, значит, провайдер режет TMDB. Программа это обходит сама: постеры качаются по кусочкам и сохраняются на компьютер, так что второй раз открываются мгновенно. Если совсем плохо, в настройках есть переключатель прокси.

## Обновления

Программа обновляется сама. Когда выходит новая версия, внизу появится плашка «Доступно обновление», жмёшь «Обновить», и всё. Можно и не жать: поставится при следующем выходе из программы.

Лайки, избранное и настройки при обновлении не теряются. Программа ещё и сама держит их резервную копию. А если хочется подстраховаться, в настройках есть экспорт в файл.

## Приватность

- Никаких аккаунтов и регистрации в программе.
- Ничего не собираю и не отправляю: ни статистику, ни твои лайки.
- Все данные лежат только у тебя на компьютере.

## Вопросы

**Есть на Mac / телефон?**
Пока только Windows. Версия для телефона в планах.

**Где смотреть фильмы?**
Программа помогает выбрать, что посмотреть, но сама фильмы не показывает. Кнопка «Смотреть» просто ищет фильм в поиске.
