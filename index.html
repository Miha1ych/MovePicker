Установка Movie Picker
1 / 4

Скачайте расширение

Нажмите кнопку ниже и скачайте архив с версией Movie Picker для вашего браузера. После скачивания распакуйте ZIP-архив в удобное место.

Скачать расширение

Откройте страницу расширений

Откройте страницу управления расширениями в вашем браузере. Можно просто вставить этот адрес в адресную строку.

chrome://extensions/
Google Chrome

Включите режим разработчика

Найдите переключатель Developer mode или «Режим разработчика» и включите его.

Загрузите расширение

Нажмите Load unpacked / «Загрузить распакованное расширение». Затем выберите распакованную папку Movie Picker, внутри которой находится файл manifest.json.

Как открыть Movie Picker

После установки расширение можно открыть сочетанием клавиш Ctrl + Shift + Y.

Ctrl + Shift + Y

Также можно закрепить Movie Picker на панели браузера через меню «Расширения» или значок 🧩. После этого расширение можно открывать одним кликом по его иконке.
